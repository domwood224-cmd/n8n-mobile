# n8n Mobile

Android client for n8n workflow automation.

## Features
- Connect to any n8n instance (self-hosted or cloud)
- Browse workflows with active/inactive status
- Toggle workflows on/off
- View execution history
- Encrypted credential storage

## Setup
1. Install the APK
2. Open Settings
3. Enter your n8n instance URL and API key (n8n → Settings → API)
4. Browse and manage your workflows
